Return Values

Learn to write functions that give back results you can store, combine, and build upon — from pure functions and booleans to recursion and input validation.

6.1  Return Values

Built-in functions like abs() and math.sqrt() produce results you can store in variables or weave into expressions. The return statement lets your own functions do the same.

import math

def circle_area(radius):
    area = math.pi * radius**2
    return area
>>> circle_area(5)
78.53981633974483

Key Insight

The variable area is local to the function. Once the function returns, you can't access it from outside — only the returned value survives.

6.2  Functions That Return None

If a function has no return statement, it automatically returns the special value None. Functions that use print() to display output still return None.

def repeat(word, n):
    print(word * n)

result = repeat('Spam, ', 3)
print(result)
Spam, Spam, Spam, 
None

Pure Function

A pure function doesn't display anything or cause side effects — it only returns a value. Prefer pure functions when you want composable, testable code.

def repeat_string(word, n):
    return word * n   # pure — no print!

line = repeat_string('Spam, ', 4)
>>> line
'Spam, Spam, Spam, Spam, '

6.3  Return Values & Conditionals

When you place return statements inside conditionals, every possible execution path must hit a return. Otherwise your function can silently return None.

# ✗ Incorrect — misses the case x == 0
def absolute_value_wrong(x):
    if x < 0:
        return -x
    if x > 0:
        return x
    # x == 0 falls through → returns None!
# ✓ Correct
def absolute_value(x):
    if x < 0:
        return -x
    else:
        return x

Dead Code

Any code placed after a return statement that always executes is dead code — it can never run, and usually signals a misunderstanding.

6.4  Incremental Development

Build functions in small, testable steps. Start with a stub that returns a placeholder, add one computation at a time, verify with print(), and finally replace scaffolding with clean return statements.

# Step 1 — stub
def distance(x1, y1, x2, y2):
    return 0.0

# Step 2 — compute deltas
def distance(x1, y1, x2, y2):
    dx = x2 - x1
    dy = y2 - y1
    print('dx is', dx, 'dy is', dy)
    return 0.0

# Step 3 — final version
def distance(x1, y1, x2, y2):
    dx = x2 - x1
    dy = y2 - y1
    return math.sqrt(dx**2 + dy**2)
>>> distance(1, 2, 4, 6)
5.0

The 3 Rules

① Start with working code, make small changes, test after each. ② Use temporary variables and print() to inspect intermediate values. ③ Remove scaffolding once the function is correct.

6.5  Boolean Functions

Functions that return True or False are great for encapsulating tests. Since comparison operators already produce booleans, you can return them directly.

# Verbose but clear
def is_divisible(x, y):
    if x % y == 0:
        return True
    else:
        return False

# Idiomatic — return the boolean directly
def is_divisible(x, y):
    return x % y == 0
>>> is_divisible(6, 3)
True

6.6  Recursion with Return Values

Combining recursion with return values unlocks the full power of computation. The classic example is the factorial function, where n! = n × (n−1)!

def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n - 1)
>>> factorial(5)
120

Leap of Faith

Instead of tracing every recursive call, assume the recursive call returns the correct result, then verify the current step is correct. This mental shortcut makes recursion far easier to reason about.

6.7  Fibonacci

The Fibonacci sequence is defined recursively: fib(0) = 0, fib(1) = 1, and fib(n) = fib(n−1) + fib(n−2).

def fibonacci(n):
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        return fibonacci(n-1) + fibonacci(n-2)
>>> fibonacci(8)
21

6.8  Input Validation

Guard your recursive functions against bad input. Checking types and value ranges at the top prevents infinite recursion and confusing error messages.

def factorial(n):
    if not isinstance(n, int):
        print('factorial is only defined for integers.')
        return None
    elif n < 0:
        print('factorial is not defined for negative numbers.')
        return None
    elif n == 0:
        return 1
    else:
        return n * factorial(n - 1)
