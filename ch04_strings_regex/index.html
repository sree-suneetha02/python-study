Strings & Regular Expressions

Chapter 8 — Interactive Study Guide

8.1 A String is a Sequence ▼

A string is a sequence of characters — letters, digits, punctuation, or whitespace. You access individual characters using the bracket operator with an integer index.

fruit = 'banana'
fruit[0]  # 'b' — indexing starts at 0
fruit[1]  # 'a'
fruit[-1] # 'a' — last character
Index 0 is the first character; index len(s)-1 is the last.
Negative indices count backward from the end: -1 is the last, -2 is second-to-last.
Using an index equal to len(s) raises an IndexError.
8.2 String Slices ▼

A slice extracts a segment of a string using [start:end]. The start index is included; the end index is excluded.

fruit = 'banana'
fruit[0:3]  # 'ban'
fruit[:3]   # 'ban' — omit start → from beginning
fruit[3:]   # 'ana' — omit end → to end
fruit[3:3]  # '' — empty string
Think of indices as pointing between characters.
fruit[:] returns a copy of the entire string.
8.3 Strings are Immutable ▼

You cannot change a character in an existing string. Attempting s[0] = 'J' raises a TypeError. Instead, build a new string from pieces of the original.

greeting = 'Hello, world!'
new_greeting = 'J' + greeting[1:]
# 'Jello, world!'
Immutability means any "modification" actually creates a new string object.
8.4 String Comparison ▼

Relational operators (==, <, >) compare strings lexicographically. Uppercase letters sort before all lowercase letters, so 'Pineapple' < 'banana' is True.

Convert to a common case (e.g., .lower()) for case-insensitive comparison.
8.5 String Methods ▼

Strings come with built-in methods invoked with dot syntax: word.upper(), word.lower(), word.strip(), word.startswith(), word.endswith(), word.count(), word.replace(), etc.

word = 'banana'
word.upper()        # 'BANANA'
word.count('a')    # 3
word.replace('a','o') # 'bonono'
Methods return new strings — they never modify the original (because strings are immutable).
A method call is called an invocation.
8.6–8.7 Reading, Writing & Find/Replace ▼

Open files with open(). Use mode 'w' to write. Loop through lines, use in to search, .replace() to substitute, and .write() to output.

reader = open('book.txt')
writer = open('output.txt', 'w')
for line in reader:
  writer.write(line.replace('old', 'new'))
writer.close()
startswith() and endswith() test prefixes/suffixes.
break exits a loop early.
8.8–8.9 Regular Expressions ▼

The re module provides powerful pattern matching. re.search(pattern, text) returns a Match object (or None). re.sub() performs substitution.

import re
re.search('Dracula', text)  # Match object
re.search('Mina|Murray', text) # | means OR
re.sub('colou?r', 'color', line) # ? makes prev char optional
| matches either alternative; parentheses group sub-patterns: cent(er|re).
^ matches start of string; $ matches end of string.
? makes the preceding character optional.
.group() returns the matched text; .span() returns start/end indices.
