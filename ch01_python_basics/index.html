1.1

Arithmetic Operators

An arithmetic operator is a symbol that represents an arithmetic computation. Python gives you six key operators:

OperatorOperationExampleResult
+Addition30 + 1242
-Subtraction43 - 142
*Multiplication6 * 742
/Division84 / 242.0
//Floor Division85 // 242
**Exponentiation7 ** 249
Watch out: In many other languages ^ means exponentiation, but in Python it's the bitwise XOR operator. 7 ^ 2 gives 5, not 49.

Integer vs Float Division

Dividing two integers with / always produces a float. Use // (floor division) to get an integer result that rounds down.

1.2

Expressions

An expression is a combination of operators and values. Python evaluates them following the standard mathematical order of operations — exponentiation first, then multiplication and division, then addition and subtraction.

Order of Operations
>>> 6 + 6 ** 2       # exponent first → 6 + 36
42
>>> 12 + 5 * 6       # multiply first → 12 + 30
42
>>> (12 + 5) * 6     # parentheses override → 17 * 6
102
Key idea: Every expression has a value. The expression 6 * 7 has the value 42. This is true no matter how complex the expression gets.
1.3

Arithmetic Functions

Beyond operators, Python provides built-in functions that work with numbers. When we use a function, we say we're calling it, and the expression is a function call.

≈

round()

Rounds a floating-point number to the nearest integer (or to n decimal places).

|x|

abs()

Returns the absolute (non-negative) value of a number.

Parentheses are required! Leaving them out causes a SyntaxError. A bare function name like abs evaluates to the function object itself.
1.4

Strings

Python represents sequences of characters as strings. You can write them with single or double quotes.

+

Concatenation

The + operator joins two strings end-to-end.

×

Repetition

The * operator repeats a string multiple times.

len

Length

len() returns the number of characters in a string.

String Operations
>>> 'Spam, ' * 4
'Spam, Spam, Spam, Spam, '
>>> len('Spam')
4
Quote style matters: Always use straight quotes (' or "). Backticks and smart/curly quotes cause a SyntaxError.

Values & Types

Every value in Python has a type. The three types we've met so far:

42

int

Whole numbers with no decimal part. E.g. 2, -7, 1_000_000.

3.14

float

Numbers with a decimal point. E.g. 42.0, 12.6.

abc

str

Sequences of characters in quotes. E.g. 'Hello'.

The type() Function

Use type() to check the type of any value.

Type Conversion

The type names int, float, and str also serve as conversion functions — e.g. int('126') converts string to integer.

Trap: Digits inside quotes are strings, not numbers. '126' / 3 throws a TypeError. Convert first with int().
Large numbers: Don't use commas — 1,000,000 becomes a tuple. Use underscores: 1_000_000.
1.6

Formal vs Natural Languages

Programming languages are formal languages — designed by people for specific purposes. They differ from natural languages:

Natural Languages

  • Full of ambiguity — rely on context
  • Redundant and verbose
  • Rich in idiom and metaphor
  • Evolved naturally over time

Formal Languages

  • Designed to be unambiguous
  • Concise and precise
  • Mean exactly what they say
  • Designed by people for specific tasks

Debugging

Programming errors are whimsically called bugs, and tracking them down is called debugging. It's one of the most valuable skills you'll develop.

Mental model: Think of the computer as an employee with strengths (speed, precision) and weaknesses (no empathy, no big-picture thinking). Channel your emotions into engagement, not frustration.
