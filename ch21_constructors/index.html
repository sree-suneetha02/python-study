Constructors in Python

Understanding how objects are created and initialized — from __new__ to __init__, default to parameterized.

Last Updated: 11 Jul 2025
01

What is a Constructor?

In Python, a constructor is a special method that is called automatically when an object is created from a class. Its main role is to initialize the object by setting up its attributes or state.

Two methods work together to manage object creation and initialization:

__new__ is the constructor that creates a new instance of the class, while __init__ is the initializer that sets up the instance's attributes after creation.

02

The __new__ Method

This method is responsible for creating a new instance of a class. It allocates memory and returns the new object. It is called before __init__.

python 
class ClassName:
    def __new__(cls, parameters):
        instance = super(ClassName, cls).__new__(cls)
        return instance
03

The __init__ Method

This method initializes the newly created instance. It is called immediately after the object is created by __new__ and is responsible for initializing attributes of the instance.

python 
class ClassName:
    def __init__(self, parameters):
        self.attribute = value
Note: __init__ is called after __new__ and does not return anything — it returns None by default.
04

__init__ vs __new__

__new__

  • Creates a new instance of the class
  • Allocates memory for the object
  • Called before __init__
  • Rarely overridden — useful for singletons & immutable types

__init__

  • Initializes the created object
  • Sets attribute values and state
  • Called immediately after __new__
  • The most commonly used constructor method
05

Types of Constructors

① Default Constructor

A default constructor does not take any parameters other than self. It initializes the object with default attribute values.

python 
class Car:
    def __init__(self):
        # Initialize the Car with default attributes
        self.make  = "Toyota"
        self.model = "Corolla"
        self.year  = 2020

# Creating an instance using the default constructor
car = Car()
print(car.make)
print(car.model)
print(car.year)
Output
Toyota
Corolla
2020

② Parameterized Constructor

A parameterized constructor accepts arguments to initialize the object's attributes with specific values provided at creation time.

python 
class Car:
    def __init__(self, make, model, year):
        # Initialize the Car with specific attributes
        self.make  = make
        self.model = model
        self.year  = year

# Creating an instance using the parameterized constructor
car = Car("Honda", "Civic", 2022)
print(car.make)
print(car.model)
print(car.year)
Output
Honda
Civic
2022

Q1 What happens if you define two __init__ methods in the same class? +

Python does not support method overloading in the traditional sense. If you define two __init__ methods, the second one overwrites the first. Only the last defined __init__ will be used. To handle multiple signatures, use default arguments or *args / **kwargs.

Q2 Can __init__ return a value other than None? +

No. If you try to return anything other than None from __init__, Python will raise a TypeError: "__init__() should return None, not 'int'". The __init__ method is strictly for initialization, not creation.

Q3 When would you need to override __new__ instead of __init__? +

You override __new__ when you need to control object creation itself — for example, implementing the Singleton pattern (ensuring only one instance exists), subclassing immutable types like int, str, or tuple, or implementing custom metaclass behavior.

Q4 What is the difference between a class attribute and an instance attribute set in __init__? +

A class attribute is shared across all instances and is defined directly in the class body. An instance attribute set in __init__ is unique to each object. Modifying a class attribute affects all instances (unless shadowed), while instance attributes are independent.

Q5 How can you simulate constructor overloading in Python? +

Since Python doesn't support multiple constructors, you can use default parameter values, *args / **kwargs, or the @classmethod decorator to create alternative factory methods like Car.from_dict(data) or Car.from_string(s).

Q6 What does super().__init__() do inside a child class constructor? +

It calls the parent class's __init__ method, ensuring the parent's attributes are properly initialized before the child adds its own. Without it, the child object may be missing attributes defined in the parent class.

Q7 Is __init__ called if __new__ returns an instance of a different class? +

No. Python only calls __init__ if __new__ returns an instance of the same class (or its subclass). If __new__ returns an object of a completely different type, __init__ is skipped.

Q8 What happens if you forget to include self as the first parameter of __init__? +

You'll get a TypeError when creating an instance because Python automatically passes the instance as the first argument. Without self, there's a mismatch in the expected number of arguments — e.g., "__init__() takes 0 positional arguments but 1 was given".
