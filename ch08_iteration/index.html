Iteration & Search

Loops, strings, counters, the in operator, and the linear search pattern

Loops and Strings

A for loop iterates through each character in a string, assigning it to a loop variable.

for letter in 'Gadsby':
    print(letter, end=' ')
G a d s b y

Building a checker function

We can encapsulate a loop into a reusable function. Here's has_e — it returns True if a word contains the letter "e":

def has_e(word):
    for letter in word:
        if letter == 'E' or letter == 'e':
            return True
    return False

Key Insight

The first return is inside the loop — it exits immediately when a match is found. The second return is outside — it runs only after the entire loop finishes without finding a match. Placing both returns inside the loop is a common bug!

Reading the Word List

Use the built-in open() function to get a file object, then iterate over its lines:

file_object = open('words.txt')
line = file_object.readline()   # returns 'aa\n'

Methods

A method is a function associated with an object, called using dot notation. readline() is a method on the file object; strip() is a method on strings.

# strip() removes whitespace from both ends
word = line.strip()   # 'aah\n' → 'aah'

Looping through a file

for line in open('words.txt'):
    word = line.strip()
    print(word)

Each iteration reads the next line. The file object tracks its position automatically.

Updating Variables & Counting

An update assigns a new value that depends on the old value. You must initialize a variable before updating it.

x = 5
x = x + 1    # increment
x += 2       # augmented assignment — same as x = x + 2

Counter pattern

A counter is a variable initialized to 0, then incremented inside a loop:

total = 0
count = 0

for line in open('words.txt'):
    word = line.strip()
    total += 1
    if has_e(word):
        count += 1
total = 113783  |  count = 76162  |  ~66.9% of words contain 'e'

The in Operator & Linear Search

Python's in operator checks membership — whether a character appears in a string:

'e' in 'Gadsby'   # False
'e' in 'Emma'     # True

Simplified has_e

def has_e(word):
    return 'e' in word.lower()

The lower() method returns a new lowercase copy of the string — the original is unchanged.

Linear Search — uses_any

def uses_any(word, letters):
    for letter in word.lower():
        if letter in letters.lower():
            return True
    return False

This pattern — looping through elements, checking each, and returning early on a match — is called a linear search.

Testing with Doctest

A docstring can include executable tests. Lines starting with >>> are treated as expressions; the following line is the expected result.

def uses_any(word, letters):
    """Checks if a word uses any of a list of letters.
    
    >>> uses_any('banana', 'aeiou')
    True
    >>> uses_any('apple', 'xyz')
    False
    """
    for letter in word.lower():
        if letter in letters.lower():
            return True
    return False

Running tests

from doctest import run_docstring_examples

def run_doctests(func):
    run_docstring_examples(func, globals(), name=func.__name__)

If all tests pass, no output is shown. A failure prints the expected vs. actual value so you can debug.
