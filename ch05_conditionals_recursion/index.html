5.1

Integer Division & Modulus

Python's integer division operator // divides and rounds down. The modulus operator % returns the remainder. Together they let you decompose numbers cleanly.

# How many full hours in 105 minutes?
minutes = 105
hours = minutes // 60      # → 1
remaining = minutes % 60   # → 45

Practical uses of %

🔢

Divisibility

If x % y == 0, then x is evenly divisible by y.

✂️

Extract digits

x % 10 gives the last digit. x % 100 gives the last two.

🕐

Clock arithmetic

(11 + 3) % 12 → 2. An 11 AM event lasting 3 hours ends at 2 PM.

5.2

Boolean Expressions

A boolean expression evaluates to True or False. These values belong to type bool, not strings. The == operator compares values — don't confuse it with =, which assigns.

💡 Common mistake: writing x = 5 (assignment) when you mean x == 5 (comparison).

5.3

Logical Operators

Combine booleans with and, or, and not. They work like their English counterparts.

x = 5

x > 0 and x < 10    # True — x is between 0 and 10

x % 2 == 0 or x % 3 == 0   # False — 5 is divisible by neither

not x > 7              # True — x > 7 is False, negated → True

⚡ Python treats any nonzero number as True in boolean context. Useful, but can be confusing — avoid relying on it early on.

5.4 – 5.7

Conditional Statements

The if statement lets your program make decisions. It checks a condition and runs code only when that condition is true.

Simple if

if x > 0:
    print('x is positive')

if / else — two branches

if x % 2 == 0:
    print('x is even')
else:
    print('x is odd')

Chained conditionals — elif

if x < y:
    print('x is less than y')
elif x > y:
    print('x is greater than y')
else:
    print('x and y are equal')

Nested → simplified

Nested conditionals can be hard to read. Use logical operators to flatten them:

# Instead of nesting two ifs…
if 0 < x < 10:
    print('x is a positive single-digit number.')

5.8 – 5.10

Recursion

A function that calls itself is recursive. Every recursive function needs a base case — a condition under which it stops calling itself. Without one, you get infinite recursion and a RecursionError.

def countdown(n):
    if n <= 0:
        print('Blastoff!')
    else:
        print(n)
        countdown(n - 1)

Visualizing the call stack

When countdown(3) runs, each call creates a new stack frame:

countdownn = 3
countdownn = 2
countdownn = 1
countdownn = 0 ← base case

▶ Try it — Recursive Countdown

5 4 3 2 1 Blastoff!

⚠ Infinite recursion happens when there's no base case or it's never reached. Python limits the call stack to ~3000 frames and raises RecursionError.

Another example: print_n_times

def print_n_times(string, n):
    if n > 0:
        print(string)
        print_n_times(string, n - 1)

5.11

Keyboard Input

Python's built-in input() function pauses the program and waits for the user to type something. It always returns a string. To get a number, wrap it with int() or float().

name = input('What is your name?\n')

speed = input('Airspeed velocity?\n')
int(speed)   # ValueError if not a valid integer!

💡 The \n in a prompt creates a line break so the user's input appears below the question.

5.12

Debugging

Error messages tell you what kind of error occurred and where it was discovered — but not always where the actual bug is. Always read carefully, but don't take them at face value.

📐

IndentationError

Invisible spaces or tabs cause these. The error points to where Python noticed — the bug might be on a previous line.

🧮

ValueError

Common with wrong division operators. Using // when you need / can produce zero, and math.log10(0) is undefined.

# Bug: // gives 0, not 0.9
ratio = 9 // 10          # → 0
math.log10(ratio)      # ValueError: math domain error

# Fix: use / for true division
ratio = 9 / 10           # → 0.9
