16.1

Creating a Point

A Point stores an x and y coordinate. In screen-graphics convention, (0, 0) is the upper-left corner; x grows rightward and y grows downward.

class Point:
    """Represents a point in 2-D space."""

    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f'Point({self.x}, {self.y})'

The translate method mutates the point in place, while translated returns a brand-new copy — mirroring the list.sort() vs sorted() pattern.

def translate(self, dx, dy):
    self.x += dx
    self.y += dy

def translated(self, dx=0, dy=0):
    point = copy(self)
    point.translate(dx, dy)
    return point
16.2

Creating a Line

A Line holds two Point objects — p1 and p2. Its __str__ leans on the Point's own __str__, so nesting works automatically.

class Line:
    def __init__(self, p1, p2):
        self.p1 = p1
        self.p2 = p2

    def draw(self):
        jumpto(self.p1.x, self.p1.y)
        moveto(self.p2.x, self.p2.y)
16.3

Equivalence vs Identity

==

Equivalence

Override with __eq__. Two objects are equivalent if their attribute values match. You decide what "match" means.

is

Identity

Cannot be overridden. Two names are identical only when they refer to the exact same object in memory.

def __eq__(self, other):
    return (self.x == other.x) and (self.y == other.y)

# After defining __eq__:
Point(200, 100) == Point(200, 100)  # True  ← equivalent
Point(200, 100) is Point(200, 100)  # False ← not identical
16.4 – 16.5

Rectangle

A Rectangle stores width, height, and a corner Point (upper-left). It builds corners via translated and draws four Line segments.

class Rectangle:
    def __init__(self, width, height, corner):
        self.width  = width
        self.height = height
        self.corner = corner

    def grow(self, dwidth, dheight):
        self.width  += dwidth
        self.height += dheight

    def translate(self, dx, dy):
        self.corner.translate(dx, dy)
16.6

Shallow vs Deep Copy

⬜

Shallow Copy

copy() duplicates the outer object but nested objects remain shared. Mutating the inner object affects both copies.

⬛

Deep Copy

deepcopy() recursively duplicates every nested object. Each copy is fully independent — no shared references.

from copy import copy, deepcopy

box2 = copy(box1)        # box1.corner is box2.corner → True  (shared!)
box4 = deepcopy(box3)    # box3.corner is box4.corner → False (independent)
16.7

Polymorphism

Greek for "many shapes." When different types provide the same method — like draw() — you can loop through a mixed list and let each object "know how to draw itself."

shapes = [line1, line2, box3, box4]

for shape in shapes:
    shape.draw()   # calls Line.draw() or Rectangle.draw() as needed
▲

Why It Matters

New shapes (Circle, Triangle, …) plug in without changing the loop. Code that consumes shapes stays open for extension and closed for modification.

16.9

Glossary

shallow copy A copy operation that duplicates the top-level object but not any nested objects it refers to.
deep copy A copy operation that recursively duplicates all nested objects, producing a fully independent clone.
polymorphism The ability of different types to provide the same interface (e.g. a draw() method), letting one loop operate on mixed-type collections.
equivalence Two objects are equivalent when == returns True, as defined by their __eq__ method.
identity Two names are identical when is returns True — they point to the exact same object in memory.
