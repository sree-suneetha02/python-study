Variables & Statements

Names, values, modules, and the building blocks of every Python program you'll ever write.

Section 2.1

Variables

A variable is a name that refers to a value. You create one with an assignment statement — a name on the left, the = operator, and an expression on the right.

🔢

Integer

n = 17

🥧

Float

pi = 3.141592653589793

💬

String

message = 'And now for ...'

An assignment statement produces no output — Python silently creates the variable. Once created, you can use it in expressions:

n + 25
42
2 * pi
6.283185307179586

You can also pass variables to functions:

round(pi) # → 3 len(message) # → 42
Section 2.2

State Diagrams

A state diagram shows each variable's name with an arrow pointing to its current value — a snapshot of the program's memory.

n → 17
pi → 3.14159…
message → 'And now for …'
Section 2.3

Variable Names

Names can contain letters, digits, and underscores — but cannot begin with a digit. Convention: use lowercase with underscores for multi-word names like your_name or airspeed_of_unladen_swallow.

Illegal Names → Syntax Errors

million! = 1000000 # punctuation!
SyntaxError: invalid syntax
76trombones = 'big parade' # starts with digit
SyntaxError: invalid decimal literal
class = 'Fresh Fruit' # keyword!
SyntaxError: invalid syntax

Section 2.4

The import Statement

A module is a collection of variables and functions. Import one to use its contents, accessed via the dot operator.

import math math.pi # 3.141592653589793 math.sqrt(25) # 5.0 math.pow(5, 2) # 25.0
💡 Tip

Both math.pow(5, 2) and the ** operator raise a number to a power. The operator (5 ** 2) is used more often in practice.

Section 2.5

Expressions vs. Statements

📐

Expression

A combination of values, variables, operators, and function calls that Python evaluates to produce a value.

⚡

Statement

A unit of code that has an effect (like creating a variable) but no value itself. Python executes statements.

# Expression — evaluates to 42 19 + n + round(math.pi) * 2 # Statement — creates a variable (no output) n = 17
Section 2.6

The print Function

In an interactive session, only the last expression's value is displayed. Use print() to display multiple results:

print(n + 2) print(n + 3)
19 20

You can pass multiple values separated by commas — print inserts spaces between them automatically:

print('The value of pi is approximately', math.pi)
The value of pi is approximately 3.141592653589793
Section 2.7

Arguments

An argument is the value you pass inside the parentheses when calling a function. Different functions accept different numbers of arguments:

int('101') # 1 arg → 101 int('101', 2) # 2 args (base 2) → 5 round(math.pi, 3) # optional 2nd arg → 3.142 print('Any', 'number', 'of', 'arguments')

Providing the wrong number or type of arguments raises a TypeError:

float('123.0', 2) # too many
TypeError: float expected at most 1 argument, got 2
math.sqrt('123') # wrong type
TypeError: must be real number, not str
Section 2.8

Comments

Comments begin with # and are completely ignored by Python. They exist to explain why, not what.

# number of seconds in 42:42 seconds = 42 * 60 + 42 miles = 10 / 1.61 # 10 km in miles
Good vs. Bad Comments

Useless: v = 8   # assign 8 to v — just repeats the code.
Useful: v = 8   # velocity in miles per hour — adds meaning the code doesn't show.

Section 2.9

Debugging

Three kinds of errors can occur. Learning to tell them apart is the key to fixing bugs quickly.

Syntax Error

The program's structure is wrong. Python refuses to run it at all and shows an error immediately.

Runtime Error

The code starts running but hits a problem mid-execution. Also called an exception.

Semantic Error

The program runs without errors but produces the wrong result. The hardest to find.

Semantic Error Example

To compute the average of 1 and 3, you might accidentally write:

1 + 3 / 2 # oops — division happens first!
2.5   ← not the average (which is 2.0)

The fix: (1 + 3) / 2 → uses parentheses to force the correct order of operations.

Glossary

variable
A name that refers to a value.
assignment statement
A statement that assigns a value to a variable.
state diagram
A visual showing variables and the values they hold.
keyword
A reserved word that defines program structure.
import statement
A statement that loads a module for use.
module
A file containing Python code, functions, and variables.
dot operator
The . used to access module contents.
evaluate
Compute the value of an expression.
execute
Run a statement and carry out its action.
argument
A value passed to a function when it's called.
comment
Explanatory text ignored by Python, starting with #.
runtime error
An error detected during execution (an exception).
semantic error
Code that runs but doesn't do what was intended.
