13.1 Filenames & Paths

Current Working Directory

Every running program has a current working directory. Use os.getcwd() to find it. This is the default directory for file operations.

import os os.getcwd() # '/home/dinsdale'

Relative vs Absolute Paths

A relative path like memo.txt is resolved against the current directory. An absolute path starts with / and works regardless of the current directory.

os.path.abspath('memo.txt') # '/home/dinsdale/memo.txt'

Listing & Checking Paths

os.listdir(dir) returns contents of a directory. os.path.exists() checks existence. os.path.isdir() and os.path.isfile() distinguish directories from files.

Cross-Platform Paths

macOS/Linux use / as separator, Windows uses \. Use os.path.join() to build paths that work on any OS.

os.path.join('photos', 'jan-2023', 'photo1.jpg') # 'photos/jan-2023/photo1.jpg'
Key Point

An ephemeral program runs briefly and loses data when it ends. A persistent program runs for a long time, keeps data in long-term storage, and can resume where it left off.

13.2 f-strings

Format Strings

An f-string starts with f before the quote. Expressions inside {} are evaluated and inserted into the string.

num_camels = 23 f'I have spotted {num_camels} camels' # 'I have spotted 23 camels'

Expressions in Braces

The braces can hold any Python expression — arithmetic, function calls, method calls, etc.

num_years = 1.5 f'In {round(num_years * 12)} months' # 'In 18 months'

Writing Formatted Data

f-strings are a clean way to write mixed data to text files. Remember to include \n for newlines — write() does not add them automatically.

w = open('book.txt', 'w') w.write(f'Years: {num_years}\n') w.write(f'Camels: {num_camels}\n') w.close()
#5 What is an f-string in Python? ▶Show
Answer

A string prefixed with 'f' that can contain Python expressions in curly braces, which are evaluated and embedded in the result string.

13.3 YAML Configuration

Serialization & Deserialization

Serialization converts an object (dict, list) to a string. Deserialization converts it back. If you serialize then deserialize, you get an equivalent (but not identical) object.

Writing YAML

Use yaml.dump(obj, file) to write a Python object into a human-readable YAML text file.

import yaml writer = open('config.yaml', 'w') yaml.dump(config, writer) writer.close()

Reading YAML

Use yaml.safe_load(file) to read YAML back into Python objects. Always prefer safe_load over load for security.

reader = open('config.yaml') data = yaml.safe_load(reader)
#6 What is YAML used for in Python programs? ▶Show
Answer

YAML is used to read and write configuration data in a human-readable text format. The yaml module provides dump() for writing and safe_load() for reading.

#7 What is serialization and deserialization? ▶Show
Answer

Serialization converts an object (like a dict) to a string. Deserialization converts the string back to an object. Round-tripping should produce an equivalent object.

13.4 Shelve — Key-Value Store

Opening a Shelf

The shelve module provides a persistent key-value store. Open with shelve.open(path, flag). Flag "c" creates if needed; "n" always creates a new empty shelf.

import shelve db = shelve.open('photo_info/captions', 'c')

Reading & Writing

Use bracket notation like a dictionary. Supports keys(), values(), items(), and the in operator.

db['jan-2023/photo1.jpg'] = 'Cat nose' print(db['jan-2023/photo1.jpg'])

Updating Mutable Values

Modifying a retrieved mutable value (like a list) does not update the shelf. You must read → modify → write back explicitly.

lst = db[key] lst.append('tops') db[key] = lst # write back!
Gotcha

Modifying a mutable value retrieved from a shelf and assigning it back is necessary because shelves store copies, not references. Always write back after mutating.

#8 What does the shelve module provide? ▶Show
Answer

A key-value store (shelf) that behaves like a dictionary but persists data to disk files. You open it with shelve.open() and access it with bracket notation.

#9 Why can't you do db[key].append(word) to update a shelf list? ▶Show
Answer

Modifying the returned list doesn't update the shelf. You must read the value, modify it, then write it back: lst = db[key]; lst.append(word); db[key] = lst.

#10 What files does a shelf create on disk? ▶Show
Answer

Typically two files: a .dat file containing the stored data, and a .dir file containing database organization info for efficient access.

13.6 Hashing & Duplicate Detection

Binary Mode

Open image files with "rb" (read binary). The result is a bytes object — a sequence of bytes rather than text characters.

data = open('photo.jpg', 'rb').read() type(data) #

MD5 Digests

A hash function computes a digest — a fixed-size fingerprint of file contents. Two identical files produce the same digest; different files almost always produce different ones.

import hashlib h = hashlib.md5() h.update(data) h.hexdigest() # 'aa1d2fc25b7ae247b2931f5a0882fa37'

Comparing Files

Instead of comparing every pair of files directly (slow), compute each file's digest and group by digest. Files sharing a digest are likely duplicates — confirm with direct comparison.

#11 What does opening a file in binary mode ('rb') do? ▶Show
Answer

It reads the file contents as raw bytes instead of interpreting them as text characters. The result is a bytes object.

#12 What is an MD5 digest and what is it used for? ▶Show
Answer

An MD5 digest is a hexadecimal string computed by a hash function from file contents. If two files have the same digest, they almost certainly contain the same data.

13.7 Walking Directories

Recursive Directory Walk

A walk function uses os.listdir to iterate a directory, printing files and recursing into subdirectories.

def walk(dirname): for name in os.listdir(dirname): path = os.path.join(dirname, name) if os.path.isfile(path): print(path) elif os.path.isdir(path): walk(path)

Filtering by Extension

Use os.path.splitext(path) to get the extension. Combine with the walk pattern to find only image files (or any target type).

os.path.splitext('photo1.jpg') # ('photo1', '.jpg')
#13 How does the walk() function work for searching directories? ▶Show
Answer

It loops through a directory's contents using os.listdir(). For files, it processes them. For subdirectories, it calls itself recursively to search deeper.

#14 What does os.path.splitext() do? ▶Show
Answer

It splits a filename into its root and extension, e.g. ('photo1', '.jpg'). Useful for checking file types.

13.8 Debugging & Glossary

Invisible Whitespace

Spaces, tabs (\t), and newlines (\n) are invisible when printed. The built-in repr() function reveals them using backslash sequences.

s = '1 2\t 3\n 4' print(repr(s)) # '1 2\t 3\n 4'

Line Endings

Different systems use different line endings: \n (Unix/macOS), \r (old Mac), or \r\n (Windows). Moving files across systems can cause issues.

#15 What does the repr() function do for debugging? ▶Show
Answer

It returns a string representation of an object that shows invisible characters like \n (newline) and \t (tab), making whitespace issues visible.
