Python Lists

An interactive study guide covering sequences, mutability, aliasing, and more — with a self-testing quiz.

📦 Lists Are Sequences

A list is an ordered collection of values (elements) enclosed in square brackets. Elements can be any type, including other lists (nesting).

cheeses = ['Cheddar', 'Edam', 'Gouda'] mixed = ['spam', 2.0, 5, [10, 20]] empty = [] len(cheeses) # → 3

✏️ Lists Are Mutable

Unlike strings, list elements can be reassigned using the bracket operator. Indices work the same as strings: zero-based, negative allowed, IndexError on out-of-range.

numbers = [42, 123] numbers[1] = 17 print(numbers) → [42, 17]

✂️ Slicing & Copying

Slice syntax [start:end] works like strings. Omit both indices to copy the entire list. You can also copy with list().

letters = ['a', 'b', 'c', 'd'] letters[1:3] # → ['b', 'c'] letters[:] # → full copy

➕ Operations & Built-ins

Use + to concatenate, * to repeat. Built-in functions sum, min, max work on numeric lists.

[1, 2] + [3, 4] # → [1, 2, 3, 4] ['hi'] * 3 # → ['hi', 'hi', 'hi']

🔧 List Methods

Key methods: append adds one element, extend adds all from another list, pop(i) removes by index and returns it, remove(x) removes by value (returns None).

t = ['a', 'b', 'c'] t.pop(1) # → 'b', t is now ['a', 'c'] t.remove('a') # → None, t is now ['c']

🔗 Lists & Strings

list(s) splits a string into characters. s.split() splits by whitespace (or a delimiter). delimiter.join(lst) joins a list back into a string.

'spam'.split() # → ... wait, no spaces list('spam') # → ['s','p','a','m'] ' '.join(['hi', 'there']) # → 'hi there'

🔀 Sorting

sorted() returns a new sorted list without modifying the original. Works on any sequence. Combine with join to sort characters of a string.

sorted(['c', 'a', 'b']) # → ['a', 'b', 'c'] ''.join(sorted('cba')) # → 'abc'

🪞 Objects, Aliasing & References

Two lists with the same values are equivalent but not identical (different objects). Assigning b = a creates an alias — both names point to the same mutable object. Changes through one name are visible through the other.

a = [1, 2, 3] b = a # alias — same object b[0] = 99 print(a) → [99, 2, 3] ← a sees the change!

📨 List Arguments

Passing a list to a function gives the function a reference to the same object. If the function mutates the list, the caller sees the change — another form of aliasing.

⚠️ Common Pitfall

Most list methods (like remove, append, sort) modify in place and return None. Don't assign the result back!

t = [1, 2, 3] t = t.remove(3) # ❌ t is now None!
