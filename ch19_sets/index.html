Section 01

Creating a Set

A set stores a collection of items with these key properties:

  • No duplicate elements — inserting the same item again is silently ignored.
  • Unordered collection — items have no specific order and cannot be accessed by index.
  • Hashing internally — makes search, insert, and delete operations efficient.
  • Mutable — you can add or remove elements, but cannot change individual elements directly.
Python
s = {10, 50, 20}
print(s)
print(type(s))
Output
{10, 50, 20}
<class 'set'>
There is no specific order for set elements to be printed — you may see them in any arrangement.

Section 02

Type Casting with set()

The set() constructor converts other iterables — like lists, tuples, or strings — into a set, automatically removing duplicates.

Python
# typecasting list to set
s = set(["a", "b", "c"])
print(s)

# Adding element to the set
s.add("d")
print(s)
Output
{'c', 'b', 'a'}
{'d', 'c', 'b', 'a'}

Section 03

Unique & Immutable Elements

Sets automatically discard duplicate values. While the set itself is mutable (you can add/remove), individual elements cannot be changed by assignment.

Python
# a set cannot have duplicate values
s = {"Geeks", "for", "Geeks"}
print(s)

# values of a set cannot be changed
s[1] = "Hello"
print(s)
Output
{'Geeks', 'for'}
TypeError: 'set' object does not support item assignment

s = {"Geeks", "for", "Geeks"} — the duplicate "Geeks" is removed, only unique values remain. s[1] = "Hello" raises a TypeError because set elements cannot be changed directly. Only add() or remove() can modify a set.

Section 05

Frozen Sets

A frozenset is an immutable version of a set. Its elements cannot be changed after creation, but you can perform operations like union, intersection, and difference. Use frozenset() to create one.

Python
# Normal set (mutable)
s = set(["a", "b", "c"])
print("Normal Set:", s)

# Frozen set (immutable)
fs = frozenset(["e", "f", "g"])
print("Frozen Set:", fs)
Output
Normal Set: {'a', 'c', 'b'}
Frozen Set: frozenset({'e', 'g', 'f'})
Frozensets are immutable, so methods like add() or remove() cannot be used. They are hashable, which allows them to be used as dictionary keys.

Section 06

Internal Working (Hash Table)

Python sets are implemented using a hash table, similar to dictionaries, where set elements are stored as keys with dummy values. When multiple elements map to the same index, Python handles the collision using chaining.

  • Each index in the hash table represents a possible hash value where elements are stored based on their computed hash key.
  • When two elements map to the same index, they are linked together using a linked list, forming a chain at that position.
  • This chaining mechanism handles collisions efficiently, allowing multiple elements to exist at the same hash index without overwriting each other.
This is why sets give O(1) average-case performance for in, add(), and remove() — the hash table avoids scanning the entire collection.

Section 07

Set Methods

add() — inserts a new element. Duplicates are ignored automatically.

Python
s = {"a", "b", "c"}
s.add("d")
print(s)
Output
{'c', 'd', 'a', 'b'}

union() — combines two sets, returning all unique elements.

Python
a = {"x", "y"}
b = {"y", "z"}
print(a.union(b))
Output
{'z', 'y', 'x'}

intersection() — returns elements common to both sets.

Python
a = {1, 2, 3}
b = {2, 3, 4}
print(a.intersection(b))
Output
{2, 3}

difference() — returns elements in the first set but not in the second.

Python
a = {1, 2, 3}
b = {2, 3, 4}
print(a.difference(b))
Output
{1}

clear() — removes all elements, leaving an empty set.

Python
s = {1, 2, 3}
s.clear()
print(s)
Output
set()

Set Operators

Sets and frozen sets support the following operators for comparing and combining:

OperatorDescription
key in sContainment check
key not in sNon-containment check
s1 == s2s1 is equivalent to s2
s1 != s2s1 is not equivalent to s2
s1 <= s2s1 is subset of s2
s1 < s2s1 is proper subset of s2
s1 >= s2s1 is superset of s2
s1 > s2s1 is proper superset of s2
s1 | s2Union of s1 and s2
s1 & s2Intersection of s1 and s2
s1 - s2Elements in s1 but not in s2
s1 ^ s2Symmetric difference (elements in exactly one set)
