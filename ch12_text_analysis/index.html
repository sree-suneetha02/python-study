Section 12.1

Counting Unique Words

Core Idea

Read a text file line by line, split each line into words, and store each word as a key in a dictionary. The dictionary's length gives the count of unique words.

# Store each word as a key
unique_words = {}
for line in open(filename):
    for word in line.split():
        unique_words[word] = 1

len(unique_words)  # ≈ 6040

Why a Dictionary?

Dictionaries automatically handle duplicates — adding the same key again just overwrites the value. And the in operator checks membership in O(1) time.

Section 12.2

Handling Punctuation

Two Problems

1) Dashes (—) glue words together → replace with spaces before splitting.
2) Punctuation sticks to word edges → use strip() to remove it.

Processing pipeline
Raw line
→
Replace — with space
→
split()
→
strip + lower
import unicodedata

def split_line(line):
    return line.replace('—', ' ').split()

def clean_word(word):
    return word.strip(punctuation).lower()

Unicode Categories

unicodedata.category('A') → 'Lu'. Characters starting with 'P' are punctuation — used to build the string for strip().

Section 12.3

Word Frequencies

Counting Pattern

If a word is new, initialize its count to 1. If it already exists, increment. This is the classic histogram pattern with dictionaries.

word_counter = {}
for line in open(filename):
    for word in split_line(line):
        word = clean_word(word)
        if word not in word_counter:
            word_counter[word] = 1
        else:
            word_counter[word] += 1

Sorting by Frequency

Use sorted(word_counter.items(), key=..., reverse=True). Top 5 in Dr. Jekyll: "the", "and", "of", "to", "i".

Section 12.4

Optional Parameters

Default Values

A parameter like num=5 gives it a default value. Callers can override it. All required params must come before optional ones.

def print_most_common(word_counter, num=5):
    items = sorted(word_counter.items(),
                   key=second_element, reverse=True)
    for word, freq in items[:num]:
        print(freq, word)
Section 12.5

Dictionary Subtraction

Spell-Checking via Set Difference

Find words in the book that are not in a valid word list. Returns keys from d1 missing from d2.

def subtract(d1, d2):
    res = {}
    for key in d1:
        if key not in d2:
            res[key] = d1[key]
    return res

Random Numbers

Pseudorandom Generation

The random module provides choice() for uniform selection and choices() for weighted selection.

import random

words = list(word_counter)
weights = word_counter.values()

# Weighted sample — frequent words chosen more often
random_words = random.choices(words, weights=weights, k=6)

Section 12.8

Markov Analysis

Successor Maps

For each word, build a list of words that can follow it. If a successor appears multiple times, it's added multiple times — giving higher probability later.

successor_map example
"half" → ['a', 'not', 'the']
"a"     → ['bee', 'vis']
"be"    → ['but', 'vis'] 
def add_bigram(bigram):
    first, second = bigram
    if first not in successor_map:
        successor_map[first] = [second]
    else:
        successor_map[first].append(second)
Section 12.9

Generating Text

The Algorithm

Pick a starting word. Look up its successors. Choose one at random. Use that word to look up the next set. Repeat. The result reads more like English than purely random words.

Start word
→
Look up successors
→
random.choice()
→
Print & repeat

Improving Quality

Use bigrams or trigrams as keys instead of single words. Longer keys = more context = more coherent text (but less variety). This is the core trade-off in Markov generation.
