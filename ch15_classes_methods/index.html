Classes & Methods

Turning standalone functions into object-oriented methods — and unlocking Python's special method magic.

15.1 Defining Methods

Python is object-oriented: most computation is expressed as operations on objects, and objects often model real-world things. A method is simply a function defined inside a class definition.

Converting a free function into a method requires two changes: indent it inside the class block, and rename the first parameter to self (by convention).

class Time:
    """Represents the time of day."""

    def print_time(self):
        s = f'{self.hour:02d}:{self.minute:02d}:{self.second:02d}'
        print(s)

You can call a method two ways:

SyntaxExampleStyle
Function syntaxTime.print_time(start)Less common
Method syntaxstart.print_time()Idiomatic ✓

Key Idea — The Receiver

The object a method is invoked on is called the receiver. In start.print_time(), the receiver start is automatically assigned to the self parameter inside the method.

15.2 Another Method

The time_to_int function converts a Time to total seconds. As a method it looks identical except for self:

def time_to_int(self):
    minutes = self.hour * 60 + self.minute
    seconds = minutes * 60 + self.second
    return seconds
# Invoking:
start.time_to_int()   # → 34800
💡

We say we "call" a function and "invoke" a method — but they mean the same thing.

15.3 Static Methods

What if a method needs to create a new object? It can't be invoked on an instance that doesn't exist yet. The answer: a static method, which doesn't receive self.

def int_to_time(seconds):
    minute, second = divmod(seconds, 60)
    hour, minute = divmod(minute, 60)
    return make_time(hour, minute, second)

Invoked on the class itself:

start = Time.int_to_time(34800)  # → 09:40:00

15.4 Comparing Time Objects

When comparing two objects, the first becomes self and the second is conventionally named other:

def is_after(self, other):
    return self.time_to_int() > other.time_to_int()
end.is_after(start)   # → True
# Reads almost like English: "end is after start?"

15.5 The __str__ Method

If an object has a method named __str__, Python uses it whenever the object needs to become a string — via str(), print(), or f-strings.

def __str__(self):
    s = f'{self.hour:02d}:{self.minute:02d}:{self.second:02d}'
    return s
⚡

Special methods are identified by double underscores on both sides — sometimes called "dunder" methods (double-underscore).

15.6 The __init__ Method

The most important special method. Python automatically calls __init__ whenever a new object is created, letting you initialise attributes immediately.

def __init__(self, hour=0, minute=0, second=0):
    self.hour = hour
    self.minute = minute
    self.second = second
time = Time(9, 40, 0)   # → 09:40:00
time = Time()              # → 00:00:00  (defaults)
time = Time(9)             # → 09:00:00

Best Practice

When writing a new class, start with __init__ (to make creating objects easy) and __str__ (to make debugging easy).

15.7 Operator Overloading

Operator overloading lets you define how operators like + behave with your custom types by writing the corresponding special method.

def __add__(self, other):
    seconds = self.time_to_int() + other.time_to_int()
    return Time.int_to_time(seconds)
duration = Time(1, 32)
end = start + duration   # calls start.__add__(duration)
print(end)               # → 11:12:00

Three special methods fire in those three lines: __init__ creates the object, __add__ handles +, and __str__ handles print().

15.8 Debugging

An invariant is a condition that must always hold true. For Time objects: minute and second should be in [0, 60), and hour should be non-negative.

def is_valid(self):
    if self.hour < 0 or self.minute < 0 or self.second < 0:
        return False
    if self.minute >= 60 or self.second >= 60:
        return False
    return True

Use assert at the top of methods to catch invalid objects early:

assert self.is_valid(), 'self is not a valid Time'

15.9 Glossary

MethodA function defined inside a class, invoked on instances of that class.
ReceiverThe object a method is invoked on — assigned to self.
Static MethodA method that can be invoked without an instance as receiver.
Instance MethodA method that requires an object as its receiver.
Special MethodA dunder method that changes how operators/functions work with an object.
Operator OverloadingUsing special methods to define operator behaviour for custom types.
InvariantA condition that should always be true during program execution.
OOP LanguageA language providing features to support object-oriented programming.
