1.1

Arithmetic Operators

An arithmetic operator is a symbol that represents an arithmetic computation. Python gives you six key operators out of the box:

OperatorOperationExampleResult
+Addition30 + 1242
-Subtraction43 - 142
*Multiplication6 * 742
/Division84 / 242.0
//Floor Division85 // 242
**Exponentiation7 ** 249
Watch out: In many other languages ^ means exponentiation, but in Python it's the bitwise XOR operator. 7 ^ 2 gives 5, not 49.

Integer vs Float Division

Dividing two integers with / always produces a float. Use // (floor division) to get an integer result that rounds down.

Python REPL
>>> 84 / 2
42.0          # float result

>>> 84 // 2
42           # integer result (floor division)

>>> 85 // 2
42           # rounds DOWN, not to nearest
1.2

Expressions

An expression is a combination of operators and values. Python evaluates them following the standard mathematical order of operations — exponentiation first, then multiplication and division, then addition and subtraction.

Order of Operations
>>> 6 + 6 ** 2       # exponent first → 6 + 36
42

>>> 12 + 5 * 6       # multiply first → 12 + 30
42

>>> (12 + 5) * 6     # parentheses override → 17 * 6
102
Key idea: Every expression has a value. The expression 6 * 7 has the value 42. This is true no matter how complex the expression gets.
1.3

Arithmetic Functions

Beyond operators, Python provides built-in functions that work with numbers. When we use a function, we say we're calling it, and the expression is a function call.

≈

round()

Rounds a floating-point number to the nearest integer (or to n decimal places).

|x|

abs()

Returns the absolute (non-negative) value of a number.

Function Calls
>>> round(42.4)
42
>>> round(42.6)
43

>>> abs(42)
42
>>> abs(-42)
42
Parentheses are required! Leaving them out causes a SyntaxError. A bare function name like abs is a valid expression — it just evaluates to the function object itself, not a computed result.
Common Mistake
>>> abs 42
SyntaxError: invalid syntax

>>> abs           # legal, but just shows the function object
<function abs(x, /)>
1.4

Strings

Python represents sequences of characters as strings. You can write them with single or double quotes. They can contain spaces, punctuation, digits — anything textual.

Creating Strings
>>> 'Hello'
'Hello'

>>> "it's a small "     # double quotes let you include apostrophes
"it's a small "

String Operations

+

Concatenation

The + operator joins two strings end-to-end into one.

×

Repetition

The * operator repeats a string multiple times.

len

Length

len() returns the number of characters in a string.

String Operations
>>> 'Well, ' + "it's a small " + 'world.'
"Well, it's a small world."

>>> 'Spam, ' * 4
'Spam, Spam, Spam, Spam, '

>>> len('Spam')
4
Quote style matters: Always use straight quotes (' or "). Backticks and smart/curly quotes will cause a SyntaxError.

Values & Types

Every value in Python has a type. The three types we've met so far:

42

int

Whole numbers with no decimal part. E.g. 2, -7, 1_000_000.

3.14

float

Numbers with a decimal point. E.g. 42.0, 12.6.

abc

str

Sequences of characters in quotes. E.g. 'Hello'.

The type() Function

Checking Types
>>> type(2)
<class 'int'>

>>> type(42.0)
<class 'float'>

>>> type('Hello, World!')
<class 'str'>

Type Conversion

The type names int, float, and str also serve as conversion functions:

Converting Between Types
>>> int(42.9)         # float → int (truncates, doesn't round)
42

>>> float(42)         # int → float
42.0

>>> int('126') / 3    # string → int, then divide
42.0
A common trap: Digits inside quotes are strings, not numbers. '126' / 3 throws a TypeError. Convert first with int() or float().
Large numbers: Don't use commas — 1,000,000 becomes a tuple (1, 0, 0). Use underscores instead: 1_000_000.
1.6

Formal vs Natural Languages

Programming languages are formal languages — designed by people for specific purposes. They differ from natural languages (English, Telugu, French) in important ways:

Natural Languages

  • Full of ambiguity — rely on context
  • Redundant and verbose
  • Rich in idiom and metaphor
  • Evolved naturally over time

Formal Languages

  • Designed to be unambiguous
  • Concise and precise
  • Mean exactly what they say
  • Designed by people for specific tasks
Reading formal languages: They are denser than natural text. Structure matters — don't always read top-to-bottom. And small errors in spelling or punctuation can completely change meaning.
1.7

Debugging

Programming errors are whimsically called bugs, and tracking them down is called debugging. It can be frustrating, but it's one of the most valuable skills you'll develop.

A good mental model: Think of the computer as an employee with strengths (speed, precision) and weaknesses (no empathy, no big-picture thinking). Your job is to manage those strengths and weaknesses effectively — and to channel your emotions into engagement, not frustration.

Glossary

string

A category of values — int, float, and str are the types introduced in this chapter.
operand
A value that an operator acts upon. In 3 + 4, both 3 and 4 are operands.
bug
An error in a program.
debugging
The process of finding and correcting errors in a program.

Exercises

Exercise 1 — Banker's Rounding

What does round(42.5) return? What about round(43.5)? Try both, then figure out the pattern. (Hint: Python uses "round half to even" — also called banker's rounding.)

Exercise 2 — Break Things on Purpose

Try these in a Python interpreter and observe the error messages: put a + before a number (+2), try 2++2, put two values with no operator (4 2), and call round without parentheses.

Exercise 3 — What's the Type?

Predict the type of each expression, then check with type(): 765, 2.718, '2 pi', abs(-7), abs(-7.0), abs, int, type.

Exercise 4 — Arithmetic Practice

Write expressions to answer: How many seconds in 42 minutes 42 seconds? How many miles in 10 km? If you run 10 km in 42:42, what's your pace per mile (in seconds, then in minutes:seconds)? What's your average speed in mph?
